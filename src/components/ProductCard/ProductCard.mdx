## ProductCard Component

The ProductCard component is a composite commerce card built from MUI primitives. It displays a product's image, badges, name, price, and add-to-cart controls in either a compact `grid` tile or a wider `list` row layout.

## Overview

Use `grid` mode for catalog/listing pages where cards sit side by side, and `list` mode for search results or wishlist views where extra detail (description, stock status, favorite, and a help link) is useful. Quantity and favorite state are controlled by the parent via `quantity`/`onQuantityChange` and `isFavorite`/`onToggleFavorite` — the component holds no internal state.

## Design tokens

ProductCard is a composite component with no single MUI counterpart, so its tokens resolve to a plain style object (via <code>productCardStyles</code>) consumed through <code>sx</code> props rather than a registered <code>MuiProductCard</code> override. The KETO-style tag reuses the existing <code>Chip</code> component's <code>secondary</code> color.
