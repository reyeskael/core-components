## Header Component

The Header component is a top-level navigation bar built on Material-UI's AppBar. It handles logo display, user authentication state, and action buttons in a consistent layout.

## Overview

The Header adapts its right-hand controls based on whether a `user` is provided. When a user is logged in it shows a welcome message and a log-out button; when no user is present it shows log-in and sign-up buttons.
