## Input Component

The Input component is a fundamental UI element built on top of Material-UI's TextField, providing a consistent interface for text entry across the application.

## Overview

Inputs collect text from the user in forms and search fields. They come in three variants — outlined, filled, and standard — and support labels, helper text, error states, and warning states. Setting `type` renders the underlying native input as `text`, `password`, `email`, `number`, `date`, and so on; setting `multiline` renders a `<textarea>` instead. Setting `endIcon` renders an icon at the end of the input, e.g. a search or password-visibility icon.

## Design tokens

Input styles are driven by three tiers of tokens. Each variant maps to its own border/underline/background tokens per interaction state, with label, helper text, and value text colors shared across all variants.

The `warning` state has no native MUI severity, so it isn't driven by a `Mui-*` state class like `error` is — the `Input` component applies an `Input-warning` class to the TextField's root when the `warning` prop is set, and the theme overrides key off that class instead.
