## Dropdown Component

The Dropdown component is a select field built on top of Material-UI's TextField (in `select` mode), sharing the same visual language as [Input](?path=/docs/stories-input--docs) — the same border, background, label, and helper text treatment across states.

## Overview

Dropdowns let users choose one value from a fixed list of options. Like Input, they come in three variants — outlined, filled, and standard — and support labels, helper text, error states, and warning states. Pass `options` for a simple label/value list, or pass `MenuItem` elements directly as `children` for full control over each row.

Because Dropdown renders through the same `OutlinedInput`/`FilledInput`/`Input` and `InputLabel`/`FormHelperText` slots as Input, the field itself always matches Input pixel-for-pixel. The only Dropdown-specific styling is the chevron icon and the options menu (background, hover, and selected states).

## Design tokens

The field surface — border, background, label, and helper text — is driven entirely by the same <code>input.*</code> tokens documented in [Input](?path=/docs/stories-input--docs), since Dropdown renders through the same underlying MUI slots. Dropdown only introduces its own tokens for the two elements it adds on top: the chevron icon and the options menu.
