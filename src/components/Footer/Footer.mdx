## Footer Component

The Footer component is a configurable, multi-column page footer built from MUI primitives. It supports contact info with social icons, dynamic link groups, a newsletter signup form, a bottom bar with copyright text, and optional payment method badges.

## Overview

Every section is opt-in — render only what you pass. Link groups are driven by an array so any number of columns can be added without changing the component. The newsletter section manages its own email/checkbox state internally and surfaces results via the `onSubscribe` callback.

## Design tokens
