## CarouselBanner Component

The CarouselBanner component is a composite hero/banner carousel built from MUI primitives. It rotates through a list of full-bleed images, each with an optional title, subtitle, and call-to-action button.

## Overview

Use CarouselBanner at the top of a page to showcase promotions, featured content, or announcements. Navigation arrows and dot indicators can each be toggled independently, and slides can advance automatically on a timer — autoplay pauses while the user hovers over the banner. The component holds only its own slide-index state; slide content and click behavior are fully controlled via the `slides` prop.

## Design tokens

CarouselBanner is a composite component with no single MUI counterpart, so its tokens resolve to a plain style object (via <code>carouselBannerStyles</code>) consumed through <code>sx</code> props rather than a registered <code>MuiCarouselBanner</code> override.
