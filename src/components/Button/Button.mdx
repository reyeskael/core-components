## Button Component

The Button component is a fundamental UI element built on top of Material-UI's Button, providing a consistent interface for user interactions across the application.

## Overview

Buttons trigger actions or navigate to different parts of your application. They come in multiple variants, sizes, and colors to suit different use cases.
