## Chip Component

The Chip component is a compact UI element built on top of Material-UI's Chip, used to represent tags, filters, attributes, or dismissible items in a concise and interactive form.

## Overview

Chips allow users to make selections, filter content, or trigger actions. They can optionally display a delete icon via the `onDelete` prop, making them ideal for input tags and filter lists.

## Design tokens

Chip styles are driven by three tiers of tokens. The primitive tier defines raw values; the semantic tier groups them into filled and outlined concepts; the component tier maps to the exact MUI variant × color shape consumed by the theme module.
