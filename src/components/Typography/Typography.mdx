## Typography Component

The Typography component is a type-scale wrapper built on Material-UI's Typography. It provides consistent, token-driven text styles across all heading, body, and label variants.

## Overview

Typography maps every variant to a resolved set of design tokens — font family, size, weight, and line height — via the MUI theme. Swapping a brand's token values is all that is needed to restyle the entire type scale.

### Component (`src/tokens/component/typography.json`)

Each MUI variant name (e.g. `typography.h1`, `typography.body2`) maps to `fontFamily`, `fontSize`, `fontWeight`, and `lineHeight` properties resolved from the semantic tier.

For a complete list of all available props, refer to the <a href="https://mui.com/api/typography/" target="_blank" rel="noopener noreferrer">Material-UI Typography documentation</a>.
